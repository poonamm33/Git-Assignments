# Git Assignment

This repository contains  Git and DevOps assignments, practical commands, and project files.

## 🚀 Topics Covered
- Git Configuration and Initialization (`git init`)
- Staging and Committing Changes (`git add`, `git commit`)
- Branching and Merging (`git branch`, `git switch`, `git merge`)
- Remote Repositories and GitHub Push/Pull (`git remote`, `git push`, `git pull`)

##  Git Commands Reference
1. `git init` - Initialize a local Git repository
2. `git clone <url>` - Clone a remote repository
3. `git status` - Check the status of working tree
4. `git add .` - Add changes to staging area
5. `git commit -m "message"` - Commit changes with a message
6. `git push` - Push changes to remote repository
7. `git pull` - Fetch and integrate changes from remote repository
8. `git branch` - List, create, or delete branches
9. `git switch <branch>` - Switch to a branch
10. `git merge <branch>` - Join two development histories together
